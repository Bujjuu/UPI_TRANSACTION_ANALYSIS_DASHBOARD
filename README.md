# UPI Transaction Analysis Dashboard

## 📊 Project Overview

This project is an interactive Excel dashboard created to analyze UPI transaction data.

The dashboard helps identify transaction patterns, trends, transaction amounts, transaction status, and other important insights using Excel data analysis and visualization techniques.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Dashboard Visualization

## 📌 Key Analysis

- Transaction Amount by Hour
- Transaction Amount by State
- Transaction Amount by Bank
- Transaction Amount by Transaction Type
- Transactions by UPI App
- Transactions by Status
- Daily Transaction Trends
- Transaction Amount by Hour and Day

## 🎯 Dashboard Features

- Interactive filters for City
- Gender filter
- Merchant Name filter
- Merchant Category filter
- KPI cards
- Interactive charts
- Hour-wise transaction analysis
- Daily transaction analysis
